# Beithir Forge Screensaver

A fullscreen, dark-forge ambient screensaver with a glowing anvil, drifting embers, a local clock, and a subtle molten-metal palette.

## Run locally

Open `index.html` in a modern browser. For the best experience, use the **FULLSCREEN** control or press **F**. Press **Esc** to leave fullscreen.

No build step or dependencies are required. The display uses Google Fonts when a network connection is available and falls back to system fonts otherwise.
